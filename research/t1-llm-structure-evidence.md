# Transformer LLM의 능력은 어디서 오는가: 구조 관점의 1차 문헌 근거표
조사일: 2026-10-17

## 핵심 요약
- **결론:** "다음 토큰 예측"은 목표 함수가 단순할 뿐이다. 이 목표를 잘 달성하려면 문맥 속 정보를 읽고 조합해야 하고, 트랜스포머 구조(내용 기반 어텐션, 잔차 스트림, MLP 메모리, 깊이 조합, 출력 토큰의 작업 메모리 역할)가 그 계산을 학습 가능하고 병렬화 가능하게 만든다. 이 중 어텐션 구조의 효율 [1], 소형 모델의 회로 [2][4], 손실의 규모 법칙 [5][6]은 **확립**이고, 대형 모델 내부 메커니즘(ICL의 경사하강 해석 [9], 대형 모델에서 induction head의 역할 [4], 세계 모델 [11][13])은 **가설 또는 논쟁**이다.
- **구조는 필요조건일 수는 있어도 충분조건이 아니라는 증거가 더 직접적이다.** 같은 아키텍처에서 후훈련만 달라져 사람 선호가 뒤집히고 [18], 같은 구조도 데이터 분포가 맞아야 ICL이 생기며 [8], 토큰 수가 같이 늘어야 하고 [6], 추론 시간 연산 [14][16]과 RL [17]이 추론 성능을 바꾼다. "구조가 필요조건"을 직접 증명한 것은 소규모 통제 실험(순환 모델은 같은 데이터에서 ICL 안 나옴 [8])뿐이다.
- **로봇 모델(VLA)로 옮길 때 유추는 부분적으로만 유지된다.** 사전학습 VLM 백본은 인터넷 규모 지식을 가져오는 수단이고 [25][26], 행동이 고주파 연속값이 되면 단순 토큰화한 다음-토큰 예측은 성능이 낮다고 보고된다 [27]. 다만 토큰화를 압축 방식으로 바꾼 자기회귀 VLA가 flow matching VLA와 비슷한 성능이라는 저자 주장도 있어(자체 평가) [27], "연속값이라서 깨진다"는 절반만 맞다.

### 9. "구조는 필요조건이지 충분조건이 아니다": 지지·반박 증거 정리

판정(본 문서): **구조는 능력이 생길 수 있는 필요조건 후보이며, 단독으로 충분하다는 증거는 없다.** 필요조건 주장은 직접 증명된 것이 거의 없다(아래 "필요조건 지지" 열의 증거는 모두 소규모 통제 실험 또는 소형 모델 분석). 충분조건이 아니라는 증거는 같은 구조에서 다른 축을 바꿨을 때 결과가 달라진 사례로 직접 존재한다.

| 축 | 구조가 필요하다는 증거 (지지) | 구조만으로 충분하지 않다는 증거 (반박) | 태그 |
|----|-------------------------------|-----------------------------------------|------|
| **구조 자체** | 같은 데이터 분포에서 트랜스포머만 ICL이 나타나고 순환 모델은 아님 [8]. 상수 순차 연산으로 학습 병렬화 [1]. 소형 모델에서 어텐션 회로(induction head)가 ICL과 인과 연결 [4] | 필요조건의 엄밀한 증명은 없다. 트랜스포머 이외 구조로 같은 능력이 가능한지는 이번에 조사하지 않았다(확인필요) | 지지 증거는 소규모 통제 실험(확립), 일반 명제는 가설 |
| **데이터** | 해당 없음 (구조 지지가 아님) | ICL이 나타나려면 분포 특성(burstiness, 희귀 클래스)이 필요 [8]. 모델 크기와 토큰 수를 같이 키워야 함 [6]. 데이터셋 크기가 모델 크기의 상한 [10]. 학습 문장의 방향(A is B)이 일반화를 결정 [22] | 확립(해당 조건) |
| **스케일** | 손실은 N, D, C에 멱법칙 [5]. few-shot 성능이 모델 크기에 따라 오름 [7]. CoT 이득은 약 100B 이상에서 [14] | 손실 개선이 곧 능력은 아님 [5]. 창발은 지표 착시일 수 있음 [21]. 규모가 커져도 역전 일반화 실패 지속(모델 크기 전반에 걸쳐 견고) [22]. 압축에서 모델 크기만 키우면 데이터에 막힘 [10] | 손실 법칙은 확립, 능력의 질적 도약은 논쟁 |
| **후훈련** | 해당 없음 | 같은 GPT-3 구조에서 후훈련만 달리해 1.3B가 175B보다 사람 선호 [18]. 사전학습 모델 위의 순수 RL로 AIME 15.6%에서 77.9% [17] | 확립(자체 보고 포함) |
| **추론 시간 연산** | 해당 없음 | 출력 토큰 수(중간 단계 수)가 표현력을 바꾼다는 이론 [15]. CoT [14]. 난이도별 연산 배분이 14배 큰 모델을 넘을 수 있음(조건부) [16]. o1 계열이 PlanBench 소형 문제를 크게 개선하지만 길이 일반화는 약함 [24] | 이론은 표현력(확립), 실제 이득은 조건부 |

### 10. 로봇 기반 모델(VLA)로의 연결

기존 종합(research/tech.md 1절 [29])과 reference/papers--pi0.md의 내용은 다시 조사하지 않고 아래 4가지만 1차 원문으로 보강했다.

| 백본 | 트랜스포머를 다음 토큰 예측으로 사전학습 [6][7] | 사전학습 VLM을 가져다 씀 [25][26] |
| 출력 | 이산 토큰의 확률분포 | 이산화 토큰(RT-2 256 bin) [26] 또는 노이즈에서 행동으로 가는 벡터장을 회귀(π0 flow matching) [25] |
| 목표 | 교차 엔트로피(=압축 길이, C11) | flow matching은 확률분포 압축 유추가 직접 적용되지 않음. 이 점은 본 문서의 해석이고 논문이 명시한 것은 아님 |
| 시간 척도 | 문서 단위 | 최대 50 Hz [25] vs 1-3 Hz [26]. 고주파일수록 인접 토큰 상관이 커짐 [27] |
| 데이터 | 웹 텍스트 조 단위 토큰 [6] | 로봇 데이터 직접 생성. 구성 미해결 [25][29] |
| 환경과의 상호작용 | 텍스트 생성, 폐루프 오차 누적 문제가 주 문제는 아님 | 행동이 환경을 바꾸고 모방학습의 오차 누적(compounding error)이 문제 [29] |

## 11. 핵심 질문 사다리: 후속 질문 10개와 근거 있는 답

각 답은 근거표의 출처 번호를 단다. "말하면 안 되는 것"은 근거가 없거나 조건을 넘는 단정이다.

| # | 질문 | 답의 요지 | 출처 | 말하면 안 되는 것 |
|---|------|-----------|------|-------------------|
| 1 | 목표가 단순한데 왜 다양한 능력이 나오나? | 목표는 단순하지만 정확히 예측하려면 문맥 정보를 읽고 조합해야 한다. 예측은 압축과 동치라서(정보이론) 더 잘 예측하는 모델이 더 잘 압축하고, 텍스트만 본 모델이 이미지·음성 조각을 압축할 정도로 문맥 조건화가 일반적이다(조건: 모델 크기 미반영 raw 압축률). 다만 "그래서 이해한다"는 별개 논쟁이다 | [10][11][13] | "예측을 잘하면 반드시 세계 모델이 있다" |
| 2 | 구조(어텐션)가 실제로 기여한 부분은? | 질의-키로 내용에 따라 읽을 위치가 정해지고(C2), 순환 없이 병렬 학습이 가능하며(C1), 층마다 잔차 스트림에 더해 깊이로 조합한다(C3, C4). 같은 데이터에서 트랜스포머만 ICL이 나왔다는 통제 실험이 있다 | [1][2][8] | "트랜스포머만이 이런 능력을 낸다" (다른 구조 비교는 이번에 조사 안 함) |
| 3 | 지식과 회로는 어디에 있나? | MLP는 입력 패턴을 key로, 다음 토큰 분포를 value로 하는 메모리로 해석된다(소형 모델). 어텐션 헤드는 문맥 속 패턴을 복사·완성하는 회로(induction head)를 이룬다. 지식이 방향성을 가진다는 반례로 reversal curse가 있다 | [3][4][22] | "MLP만 지식을 저장한다", "대형 모델에서도 induction head가 ICL의 전부다" (후자는 가설) |
| 4 | in-context learning은 어떻게 가능한가? | 관찰은 확립이다(GPT-3). 메커니즘은 가설 셋이 공존한다: induction head(소형 모델 인과, 대형은 상관), forward pass 내 경사하강(장난감 회귀에서 증명·일치), 그리고 데이터 분포 특성(burstiness 등)이 ICL의 발현 조건이라는 통제 실험. 서로 배타적이지 않다 | [4][7][8][9] | "ICL은 경사하강이다"를 확립된 사실로 말하기 |
| 5 | 규모만 키우면 되나? 스케일링 법칙이 말하는 것은? | 손실이 N, D, C에 멱법칙을 따른다는 것이다. 능력의 질적 도약은 별개 문제이고, 배분은 모델과 데이터를 같이 키워야 하며(Chinchilla), 데이터가 모델 크기의 상한을 만들 수 있다. 후훈련과 추론 연산도 결과를 바꾼다 | [5][6][10][16][18] | "손실이 줄면 능력이 예측된다", "Kaplan과 Chinchilla는 같은 결론이다" (토큰 배분 권고가 다름) |
| 6 | 창발 능력은 실재하나? | 논쟁 중이다. 원 논문은 임계 규모 이후 급상승을 정의로 보고했고, 반론은 비선형·불연속 지표를 쓰면 창발처럼 보이고 연속 지표에서는 부드럽다고 시연했다. 반론 저자도 LLM이 창발을 못 한다고는 주장하지 않는다 | [20][21] | 어느 한쪽을 정설로 말하기. 후속 재검토는 이번에 읽지 않았다 |
| 7 | 추론, 도구, 코드는 어디서 나오나? | 추론: 출력 토큰이 중간 계산을 담는 작업 메모리로 쓰이고(이론은 표현력 확대를 증명, 실제 이득은 모델 크기와 난이도에 의존), 검증 가능한 과제에서 RL이 추론 길이와 성능을 키운다(R1-Zero AIME 15.6에서 77.9%, 자체 보고). 도구·코드: 호출을 토큰 시퀀스로 두면 같은 목표로 학습되고 코드는 자동 검증이 가능해 RL 보상으로 쓰기 좋다(후자는 가설) | [14][15][16][17][19] | "CoT가 모델의 실제 추론 과정을 그대로 보여 준다" (저자도 open question), "R1이 도구를 쓴다" (못 쓴다고 저자가 명시) |
| 8 | LLM이 세계 모델을 갖고 있다고 할 수 있나? | 오델로 같은 합성 과제에서는 내부 보드 상태 표현이 존재하고 출력에 인과적으로 쓰인다는 증거가 있다(선형으로 읽히기도 함). 반면 택시 내비게이션에서는 합법 수 예측이 거의 완벽해도 복원한 지도가 비일관이고 우회로에서 무너졌다. 영역과 지표에 따라 다르다 | [11][12][13] | "LLM은 세계 모델을 갖는다"/"갖지 않는다" 중 어느 쪽이든 일반화 |
| 9 | 어디서 실패하나? | 가중치에 학습한 사실의 역방향 일반화 실패(컨텍스트에 있으면 추론 가능). 계획: GPT-4 Blocksworld 34.3%, o1은 소형 문제 97.8%이나 6~20블록에서 23.63%로 급락. 모두 특정 모델·시점의 측정이다 | [22][23][24] | "LLM은 계획을 못 한다"를 현재 모델로 일반화 |
| 10 | 이 원리를 로봇 모델(VLA)에 그대로 쓸 수 있나? | 절반은 된다. 사전학습 VLM이 인터넷 규모 지식을 공급하는 것은 저자 주장 수준에서 유지된다. 그러나 로봇 행동 데이터는 웹에 없고, 행동이 고주파 연속값이면 단순 이산화는 성능이 낮고(인접 토큰 상관) π0는 flow matching으로 50 Hz 청크를 낸다. 한편 압축 토큰화(FAST)로 자기회귀 방식도 비슷한 성능이라는 자체 보고가 있어 "연속이라 깨진다"는 단정은 피한다 | [25][26][27][29] | "다음 토큰 예측이 VLA에도 그대로 성립한다" 또는 "연속 행동엔 자기회귀가 안 된다" |

## 확인하지 못했거나 한계가 있는 항목 (확인필요)
- **창발 논쟁의 후속 문헌:** [20][21] 이후의 재반박·재검토는 읽지 않았다 (C34).
- **ICL 경사하강 가설에 대한 반대 증거:** 이번에 조사하지 않았다 (C17).
- **트랜스포머 외 구조(상태공간 모델 등)와의 비교:** "구조가 필요조건"의 일반 명제를 가늠할 문헌은 읽지 않았다 (섹션 9).
- **코드 생성 능력의 1차 논문:** 읽지 않아 C31은 가설이다.
- **VLA 백본 효과의 대조 실험:** V1은 저자 주장이고 백본 유무 대조는 확인하지 못했다. RT-2의 구체 성공률은 인용하지 않았다.
- **개별 논문의 세부 수치는 초록·서론·표 일부만 확인했다.** 근거 수준 B로 표시한 항목의 세부 실험 조건은 원문 해당 절을 더 읽어야 한다.
- **인용 수(OpenAlex)는 조회하지 않았다.**
- **Kaplan 권고 수치:** Chinchilla 원문 텍스트 추출에서 Kaplan의 "모델 크기 증가 배수"가 깨져 있어 인용하지 않고 토큰 1.8배만 인용했다.
- **PlanBench 논문의 NeurIPS 게재 여부, Nanda 논문의 게재 학회:** reference 파일에 확인필요로 표기.

## 로봇 모델(VLA)·RX 관점 시사점
- **설명 프레임:** 고객에게 "왜 LLM 기반 모델이 로봇에 쓰이는가"를 설명할 때, 구조 덕분이 아니라 "사전학습 지식 + 로봇 데이터 + 행동 표현 선택"의 합이라고 말한다. 구조는 필요조건 후보일 뿐이라는 근거는 섹션 9에 있다.
- **데이터가 해자라는 논리의 학술적 뒷받침:** 같은 구조에서도 데이터 분포 [8]와 데이터 양 [6]이 능력을 좌우하고, 로봇 행동 데이터는 웹에서 얻을 수 없다 [29]. 현장 데이터 확보를 RX 업무의 중심에 두는 논리와 맞는다 (본 문서의 해석).
- **행동 표현의 선택은 설계 쟁점:** 자기회귀 토큰화와 flow matching은 둘 다 자체 평가 근거만 있다 [25][27]. 고객 제안에서는 특정 방식의 우위를 단정하지 않고 평가 조건을 먼저 묻는다.
- **후훈련·추론 시간 연산은 현장 배포 이후에도 성능을 바꾸는 축이다.** 사전학습 이후 교정·RL로 개선하는 흐름 [17][18]은 로봇의 현장 교정 데이터 학습과 같은 구조라고 볼 수 있다 (유추. 로봇 쪽 근거는 research/tech.md 2절 [29]).
