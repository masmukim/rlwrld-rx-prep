## 핵심 사실
- π0.7 공개일 2026-04-16. 핵심 주장은 "compositional generalization": 서로 다른 맥락의 기술을 조합해 처음 보는 작업을 해결.
- 사례: 에어프라이어 작업 관련 학습 에피소드가 2개뿐인데도, 단계별 말 지시를 주면 고구마를 조리하는 데 성공.
- 사전학습: 웹 규모 데이터 + 작업별 데이터. 기존 방식("작업마다 데이터 수집, 전문가 모델 학습, 반복")을 벗어난다고 설명.
- 기사 기준 누적 조달 10억 달러 이상, 직전 평가 56억 달러, 새 라운드는 약 110억 달러 평가 협의 중.
- 사업 모델은 미공개. 상용화 시점을 투자자에게 제시하지 않음.
- 한계(기사): 복합 다단계 작업을 자율 수행 못함("토스트 만들어줘" 불가). 외부 검증용 표준 로보틱스 벤치마크 없음. 프롬프트 개선에 따라 성공률이 5%에서 95%까지 달라짐.
- 하드웨어 상세는 기사에 없음.
