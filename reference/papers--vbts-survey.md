## 핵심 사실
- 문제: 시각 기반 촉각 센서(VBTS)의 하드웨어, 학습, 시뮬레이션을 하나의 파이프라인으로 정리
- 방법: 엘라스토머 설계, 센서 차원, 광학 구성별 하드웨어 분류 + 신호처리부터 정책과 파운데이션 모델까지 학습 계층 + 시뮬 플랫폼, 데이터셋, sim-to-real, 센서 간 적응
- 결과/한계(저자 서술): 표준화, 센서 내구성, 제조 확장성, 데이터 수집, sim-to-real 성능이 여전히 배치 장벽. 센서가 "sparse, low-dimensional signals"를 주는 한계

## 원문 발췌
> deployment obstacles in standardization, sensor durability, manufacturing scalability, data collection, and sim-to-real performance (WebFetch 요약 기준)

## 메모 (RX 관점)
- "촉각 센서 내구성과 제조 확장성"이 학계가 인정하는 미해결 과제 -> 고객 PoC에서 촉각 센서를 필수로 넣을지 선택 사양으로 둘지 판단 근거.
