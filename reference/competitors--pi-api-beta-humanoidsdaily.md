## 핵심 사실
- PI가 로봇 모델 학습·추론용 베타 API를 발표(기사 표기 10월 13일). 개발자는 PI 관리 인프라에서 미세조정하고 호스팅 추론을 쓴다. 접수는 신청제, 배치 단위 온보딩.
- 흐름: 팀이 시연을 올려 정책을 학습하고 하드웨어에서 시험한 뒤 실패 주변 데이터를 더 수집. 데이터 수집과 평가는 개발 과정에 남는다.
- 사례(기사): Almond의 Axol 양팔 로봇이 스페이서 디버링을 API 반복 4일 만에 시연. Actor의 휠 로더가 덤프트럭 적재(상용 배치). 대부분 사례가 클라우드 추론.
- 이미 openpi로 π0, π0-FAST, π0.5 체크포인트와 예제를 배포(기사 서술).
- 신청서 항목: 로봇 구성, 학습 경험, 보유 텔레오퍼레이션 데이터, 예정 시뮬레이션 데이터, 작업 성공 기준, 추론 위치(클라우드/로컬).
- 데이터 소유·사용 조건, 가격은 기사에 없음.

## 원문 발췌
