## 핵심 사실
- TX GHOST가 편의점에서 음료 보충 대부분을 자동화하고 있으나, 예측하기 어려운 오류와 복구 패턴이 많아 원격 조작을 병행. 예: 진열대 안에서 굴러 넘어진 음료 복구.
- 역할 분담: TX는 매장에서 도는 로봇과 텔레오퍼레이션 데이터를 제공하고 PI의 VLA를 결합. PI는 실제 생산 데이터로 학습해 오류 복구 정책을 개발.
- 데이터 주입 -> 학습 -> 재배포의 훈련 루프를 만든다는 목표. 협력은 이미 진행 중이며 상세는 추후 공개.

## 원문 발췌
> TX will provide robots running in retail stores along with its teleoperation data ... PI will develop policies that address the challenges of recovering from error cases by training PI's VLA models on data generated during real production.
