## 핵심 사실
- 2026-01-27 공개. Helix 02는 걷기, 조작, 균형을 하나의 신경망 시스템으로 통합한 전신 자율 시스템.
- 3계층: System 0(1 kHz, 균형·협응, 10M 파라미터, 사람 모션 1,000시간 이상 리타게팅 데이터와 20만 개 이상 시뮬 환경으로 학습), System 1(200 Hz, 헤드 카메라·손바닥 카메라·손끝 촉각 센서·전신 고유수용성 입력 -> 관절 명령), System 2(장면 이해와 언어 해석).
- Figure 03 손: 손바닥 카메라(가림 상황의 손 안 시각 피드백), 손끝 촉각 센서(클립 하나 무게 수준, 3 g 정도 힘 감지).
- 시연: 61개 연속 동작의 약 4분 식기세척기 적재·하역, 알약 꺼내기, 5 ml 주사기 분주, 클러터에서 금속 부품 꺼내기, 병뚜껑 풀기.
- 고객·배포 정보는 이 페이지에 없음.

## 원문 발췌
> True autonomy requires something fundamentally different: a single learning system that reasons over the whole body at once.
