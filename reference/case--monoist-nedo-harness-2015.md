(WebFetch 요약 기준. 원문 저장본은 문자 인코딩이 깨져 Grep 불가. 본문 인용 시 "WebFetch 요약"으로 표시.)
- 2015년 NEDO 사업 "ワイヤーハーネス製造自動化の実用化技術開発"의 助成先은 オートネットワーク技術研究所와 住友電装 (WebSearch 요약 기준 / 기사 도입부).
- 대상 공정: 케이블 **분기·결속**, **클램프** 장착(차량 고정 부품), **외장품** 장착. 케이블 형상이 작업 중 바뀌어 로봇 도입이 어렵다는 서술.
- 개발 2축: ① 로봇의 장점을 살린 신공법 — 다수 케이블을 정렬시키고 비전 시스템과 **복수의 로봇 핸드**로 분기·결속하는 시스템 ② 분기·결속 후 케이블에 클램프·외장품을 장착하는 로봇 시스템.
