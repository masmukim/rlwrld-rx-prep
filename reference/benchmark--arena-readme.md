## 핵심 사실
- Arena v0.3은 알파: "APIs are unstable ... Do not use this in production." 라이선스 Apache 2.0, Isaac Sim은 독점 구성요소를 포함.
- Published Benchmarks에 Lightwheel RoboFinals, RoboCasa Tasks, LIBERO Tasks, RoboTwin 2.0 등. DexBench는 목록에 없다.
- Coming Soon에 RLWRLD(DexBench), UC Berkeley, X Square, Sharpa, NVIDIA GEAR(G1 Factory)의 벤치마크 통합이 예정으로 적혀 있다.
- 권장 게시 방식: 벤치마크는 각자 저장소에서 관리하고 Arena 통합 브랜치나 패키지를 둔다.

## 원문 발췌
> Coming soon: support for the full RoboTwin and RoboDojo task suites, plus benchmark integrations from ecosystem partners including RLWRLD (DexBench), UC Berkeley, X Square, Sharpa, and NVIDIA GEAR (G1 Factory), with more partner benchmarks to follow.
