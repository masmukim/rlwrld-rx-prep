@plan.md

### 1. 대상 찾기
상태가 `대기`이고 선행 작업이 모두 `완료`인 작업을 찾는다. 없으면 이유(어떤 선행 작업이 남았는지)를 보고하고 멈춘다.

### 2. 배정 먼저
에이전트를 띄우기 **전에** 메인 에이전트가 plan.md에서 대상 작업 전부의 담당과 상태(`진행중`)를 한 번에 바꾼다. 서브에이전트는 plan.md를 건드리지 않는다.

### 3. 동시 실행
`/rx-run`의 담당 표대로 대상 작업마다 에이전트를 **한 메시지에서 동시에** 띄운다. 각 에이전트는 자기 산출물 파일만 쓴다.

### 4. 검증과 완료
에이전트가 끝나는 대로 작업마다 `fact-checker` 검증을 거친 뒤 `.claude/skills/rx-done/SKILL.md`를 읽고 그 절차를 따른다. 커밋은 작업마다 하나씩 한다. git 충돌을 막기 위해 커밋과 푸시는 메인 에이전트가 순서대로 한다.

B1이 포함되면 `/rx-run`의 4-1 단계(사용자 결정)를 거친다.

### 5. 보고
완료된 작업, 실패하거나 중단된 작업, 새로 시작할 수 있게 된 작업을 보고한다.
