# ROI 모델

## 시트 구성 (case/roi.xlsx)

### 가정 시트
항목, 값, 단위, 출처 또는 `추정` 근거 열로 만든다. 입력 셀은 파란 글씨로 표시한다.

| 구분 | 항목 |
|------|------|
| 현재 인력 | 대체 대상 인원(교대당), 교대 수, 연간 가동일, 1인당 연간 총인건비(4대보험·복리후생 포함) |
| 로봇 투자 | 로봇 팔·손·센서 단가, 대수, 시스템 통합비, 작업대·지그, 초기 데이터 수집·학습비 |
| 운영 비용 | 연간 유지보수비(투자비 대비 %), 소프트웨어·모델 라이선스, 관리 인력, 전력 |
| 성능 | 사람 대비 처리 속도, 가동률, 작업 성공률, 대체율(로봇 1대가 대체하는 인원) |
| 재무 | 할인율, 분석 기간(5년), 감가상각 기간 |

**가정값은 지어내지 않는다.** 공개 자료로 확인한 값은 출처를 적고, 나머지는 `추정`으로 표시하고 근거(예: 유사 사례, 범위의 중간값)를 적는다.

### 계산 시트
모든 셀은 가정 시트를 참조하는 **엑셀 수식**으로 넣는다.
- 연간 절감 인건비 = 대체 인원 × 교대 수 × 1인당 연간 총인건비 × 대체율
- 총 투자비 = (로봇 단가 × 대수) + 시스템 통합비 + 작업대·지그 + 초기 데이터·학습비
- 연간 운영비 = 유지보수비 + 라이선스 + 관리 인력 + 전력
- 연간 순효과 = 연간 절감 인건비 × 가동률 × 성공률 − 연간 운영비
- 단순 회수 기간(년) = 총 투자비 ÷ 연간 순효과
- NPV = −총 투자비 + Σ(연간 순효과 ÷ (1+할인율)^t), t = 1…5 (엑셀 `NPV()` 함수 사용)

### 민감도 시트
- 가동률(60~95%)과 로봇 단가(−30%~+30%)의 2차원 표로 회수 기간을 보여 준다.
- 결과를 가장 크게 흔드는 변수 2개를 시트 상단에 적는다.

## 실행 환경
Python은 `.venv/bin/python`으로 실행한다 (openpyxl 설치됨). Anaconda `python3`는 쓰지 않는다.

## 결과 해석 기준
- 회수 기간과 함께 비재무 효과(인력난 해소, 품질 일관성, 야간 가동)를 따로 적는다.
- 모델 결과는 "이 가정이면 이렇다"로 말한다. 단정하지 않는다.
