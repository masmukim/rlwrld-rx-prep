# 리서치 문서 형식

## 템플릿
```
# <주제>
조사일: YYYY-MM-DD

## 핵심 요약
- (3줄)

## 본문
(표 우선. 아래 주제별 구성 참고)

## RX 관점 시사점
- 고객 제안에서 어떻게 쓰이는가
- 면접에서 어떻게 말할 수 있는가

## 출처
1. [제목](URL) - 발행처, 발행일
```

## 출처 규칙
- 본문의 수치와 주장마다 `[1]`처럼 출처 번호를 붙인다.
- 1차 소스(회사 발표, 공식 블로그, 논문, 공시)를 우선 쓴다. 기사뿐이면 기사라고 표시한다.
- 소스끼리 다르면 둘 다 적고 어느 쪽을 택했는지 이유를 쓴다.
- 확인하지 못한 값은 `추정`으로 표시하고 근거를 적는다.
- 숫자에는 단위, 기준 연도, 통화를 명시한다.
