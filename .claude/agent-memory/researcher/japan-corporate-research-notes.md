- 잘 열린 1차: sumitomoelectric.com/jp/id/project/v20/04, v28/04 (일본어·영어판 둘 다 `id/project/...`로 열림), sumitomo.gr.jp/english/act/social-issue/sws, sebn.com 제품 시트 PDF(wp-content/uploads), newswitch.jp/p/<번호>.
- 막힘: nikkan.co.jp 405, mdpi.com 403, izb-online.com 전시 소개 페이지는 검색 결과에 있어도 열면 404(Wayback도 404), netdenjd 본문 유료.
- WebSearch 요약 모델은 URL이 안 열리는 페이지의 문장을 "인용"처럼 돌려준다. 열리는 원문으로 확인되기 전에는 인용하지 않는다.
- **일본어판과 영어판 수치·시제가 다를 수 있다**: 住友 그룹 페이지 `高められる`(가능) vs "has been increased"(완료), id v20 세트 공법 리드타임 일본어 "大幅に短縮" vs 영어 "2 hours". 원문은 일본어로 택하고 불일치를 적는다.
- 잘 통한 검색어: `e-STEALTH W/H automation rate`, `住友電装 セット工法 切圧線`(절압선 아님, 切圧線이 맞음), `住友電装 漆畑 インタビュー`.
- 자동화율처럼 기업이 정의 없이 쓰는 지표는 "분모 미공개"가 결론일 수 있다. 찾은 시간을 늘리기 전에 문언 증거(工数 vs 工程 구분)와 서술 대상(라인/제품/전사)을 먼저 표로 정리한다.
