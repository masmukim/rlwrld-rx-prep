- 가장 값진 소스: 유라코퍼레이션 지속가능경영보고서 PDF(yurasrbija.rs 게시본, fetch.py로 열림). 국내/해외 생산직, 외국인, 간접고용 사업장별 표가 있음. 다른 하네스사(경신, THN)도 ESG 보고서/DART를 먼저 찾을 것.
- 열림: marklines.com/en/top500/<회사> (공개 구간에 연혁, 주주), savannahjda.com, magazine.hankyung.com, inews24, president.jp, 岩手県 PDF, jobploy.kr(워크넷 공고).
- 막힘: dqsglobal.com(403), jobplanet(403), mydailybyte(429), dart.fss.or.kr(동적, 에이전트 접근 불가), kyungshin.co.kr(연결 거부), yadda.icm.edu.pl(403), assemblymag(403), miyazaki-u repo(406).
- 검색 요약 함정: 같은 질문을 두 번 검색하면 요약이 "확인됨"과 "확인 못 함"으로 갈린다(유라 17만 사양). 원문 열람 전에는 미확인으로 둔다. 검색 요약이 "AI 생성" 표기 문단(잡플로이)을 사실처럼 옮기기도 한다.
- fetch.py는 URL에 한글이 있으면 ascii 오류로 실패한다. 한글 없는 단축 URL을 쓴다.
- koreascience.kr 하네스 학회 논문은 라인 데이터가 없다(시간 낭비). 하네스는 통계상 전기장비 제조업이라 "자동차부품"으로 찾으면 안 잡힌다.
- 국내 라인 단위 수치(인원, 택트, 품번)는 공개 자료에 거의 없다. 현장 인터뷰와 DART 항목 요청으로 넘기는 편이 빠르다.
