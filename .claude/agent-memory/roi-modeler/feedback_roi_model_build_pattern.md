계산 시트를 "열 = 시나리오, 행 = 동일 수식"으로 만들고, 구 가정(analysis.md 7.5절)을 재현하는 열을 같이 둔다(인건비·유지보수 직접 입력 override 행). 그러면 신규 입력(Q7/Q8)을 쓰면서도 이전 문서 값(5.7년, 10.6년, 77년, 7.0년)과 대조가 된다.

**Why:** 입력 우선순위가 바뀌면(Q7/Q8 > analysis.md) 기본 결과가 달라져서 "값이 맞는지" 판단 기준이 사라진다. 구 가정 열이 검산 기준이 된다.

**How to apply:** 민감도 표는 net/투자/회수/NPV를 Python 문자열 빌더로 한 식에 합쳐(파라미터만 치환) 각 셀에 넣는다. 검산 시트에는 Python 독립 계산값을 숫자로 붙이고 시트 수식과의 차이·판정 열을 둔다. 토네이도는 회수 기간이 텍스트("회수 불가")일 수 있어 NPV 폭으로 순위를 매긴다. 문서 값이 반올림이라 허용오차는 Python 정확값 기준으로 잡고 문서 값은 참고 열에 둔다.

**수정 모드 패턴 (B8, 2026-10-12):** 빌드 스크립트가 저장소에 없다. roi.xlsx를 `openpyxl.load_workbook`으로 열어 기존 시트 아래에 새 절을 덧붙이고(행 삽입 금지, 참조가 깨짐), 기존 셀 스타일은 `copy()`로 복제한다. 시나리오별 비교는 기존 계산 열 대신 민감도 시트에 열 그룹(가격별 + 차이)으로 자기완결 블록을 만들고, 검산 시트에 Python 독립값을 붙인다. 연동/비연동처럼 모델 방식이 갈리는 변수는 두 값을 분리해 두면 외부 근사(Q9 3.3년 = 비연동, 시트 연동 = 2.93년)와 대조가 설명된다.
